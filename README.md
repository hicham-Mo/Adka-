# نور الاستخلاف

نظام وكيل ذكي متعدد الخبراء، مع واجهة ويب وقاعدة Python FastAPI تدير استدعاءات نماذج Groq / Gemini / Claude، مع دعم خبراء متخصصين، أوامر متوازية، وسجلات تنفيذ.

## الوصف

هذا المشروع يقدّم أساسًا عمليًا لنظام "نور الاستخلاف" يعمل كـ:

- وكيل مركزي يوزع الطلبات على نماذج متعددة.
- خبراء متخصصون بأدوار محددة مثل: تفسّر القرآن، قانون، مالية، أمن، تطوير، تحليل بيانات، محتوى، وبنية سحابية.
- واجهة ويب عربية/RTL لتجارب سريعة في المتصفح.
- نقطة دخول Backend وقابلة للاتصال مع APIs الحقيقية عند توفر المفاتيح.
- نظام احتياطي يسمح بتشغيل النظام محليًا حتى بدون مفاتيح API.

## التشغيل السريع

1. إنشاء البيئة الافتراضية:

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# أو على Windows: .venv\Scripts\activate
```

2. تثبيت الاعتماديات:

```bash
pip install -r requirements.txt
```

3. نسخ ملف المتغيرات البيئية:

```bash
cp .env.example .env
```

4. تشغيل الخادم:

```bash
python run.py
```

أو مباشرة:

```bash
uvicorn backend.app:app --reload --host 0.0.0.0 --port 8000
```

5. فتح الواجهة:

```text
http://127.0.0.1:8000
```

إذا كنت تستعمل صفحة HTML ثابتة مباشرة من `frontend/index.html`، استخدم خادم ملفات محلي، مثال:

```bash
python -m http.server 9000 --directory frontend
```

ثم افتح:

```text
http://127.0.0.1:9000
```

## إعداد المفاتيح

راجع ملف `.env.example`، ثم أضف مفاتيحك:

```env
GROQ_API_KEY=...
GEMINI_API_KEY=...
ANTHROPIC_API_KEY=...
```

إذا لم تضف أي مفتاح، سيعمل النظام في وضع "النسخة الاحتياطية" (fallback) مع استجابات تجريبية، ما يساعد على اختبار البنية دون الاعتماد على external APIs.

## نقطة الاتصال الرئيسية

### POST /api/query

النموذج المرسل:

```json
{
  "model": "groq",
  "expert": "حكيم القرآن",
  "prompt": "اكتب ملخصًا حول السلام في النصوص الإسلامية"
}
```

الرد المتوقع:

```json
{
  "response": "...",
  "model": "groq",
  "expert": "حكيم القرآن",
  "provider": "groq",
  "status": "ok"
}
```

### GET /health

```json
{
  "status": "ok",
  "service": "نور الاستخلاف",
  "version": "0.1.0"
}
```

## ملاحظات مهمة

- لا تضع مفاتيح API في المتصفح أو في أي ملف يُعرض للجمهور.
- استخدم `CORS` فقط للنطاقات المسموح بها في الإنتاج.
- أضف المصادقة والتأمين في البيئة الإنتاجية.
- استخدم `rate limiting` و`request timeout` للتحكم في الاستهلاك.
- أضف سجلًا دائمًا وخادم مزامنة في بيئة الإنتاج.
